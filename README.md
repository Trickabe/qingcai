# 青财智管（概念 Demo）

面向大学生与初入职场青年的智能成长型金融服务平台前端概念演示。项目围绕“资产智能管理 + 金融素养提升”构建，所有数据均为浏览器内的 Mock 数据，不涉及真实资金、交易或投资建议。

## 在线演示

概念 Demo 已发布到 GitHub Pages，无需安装任何环境即可打开：

**https://trickabe.github.io/qingcai/**

线上版本运行纯前端 Mock 数据。后端联调（`/backend` 代理）仅在 `localhost` 与 `127.0.0.1` 下启用，因此线上不会产生无效请求。

关于部署方式、后续更新和故障排查，见 [DEPLOY.md](DEPLOY.md)。

## 运行方式

直接用浏览器打开 `index.html` 可体验 Mock 数据。要使用登录和本机后端接口，请在当前目录运行：

```powershell
node dev-server.js
```

## 已实现模块

- 今日概览：资产概况、财务健康度、预算和风险提醒。
- 资产管理：收支趋势、分类统计、交易记录、预算调整、储蓄目标新建。
- AI 财富管家：以对话框为主的问答页，可接入真实 AI 接口（OpenAI 兼容），未配置时自动使用本地模拟回答；顶部为定制建议 banner，储蓄提醒与理财偏好画像已分别并入资产页和风险预警页。
- 风险预警：风险等级、现金流预测、消费异常和防诈提醒。
- 金融学习：个性化学习路径、课程内容和本地判分测验。
- 模拟金融实验室：虚拟本金、场景任务、资产配置与复盘。
- 青年成长账户：等级、成长值、徽章、权益和成长记录。
- 设置与授权：个人资料表单及本地模拟授权状态。

## 数据与接口说明

前端状态默认保存在 `app.js` 的 `state` 中，未连接服务时可完整体验 Mock 演示。现在已接入 `https://localhost:7285` 的接口：

- `POST /login`、`POST /register`：设置页可登录或注册，并将令牌保存在浏览器本地。
- `/api/account`：读取、创建、修改账户；资产页显示账户余额并提供账户表单。
- `/api/userInfo`：读取、修改昵称、身份、学校和性别。
- `/api/transaction`：读取、创建、修改、删除交易；提交后会刷新账户与交易数据。写入请求使用后端字段名 `Amount`、`Description`、`CategoryId`、`ByAccountId`，确保选定账户的真实 ID 被传递。
- `/api/asset`：登录后会一并读取资产数据，为后续资产明细扩展保留。
- `/api/Panel/TotalMoney`、`/api/Panel/MonthlyIncome`、`/api/Panel/MonthlyExpenses`、`/api/Panel/MonthlyBudget`：今日概览页的总资产、本月收入、本月支出与本月预算，读取失败时自动回退到本地 Mock 数据；`POST /api/Panel/MonthlyBudget` 用于设置本月预算（请求体为 JSON 数字，如 `3000`）。

`callApi(endpoint, options)` 是统一请求封装，会自动附带登录令牌。开发服务器会把前端的 `/backend/*` 请求转发到 `https://localhost:7285/*`，从而避免浏览器的跨域限制和本机开发证书信任问题。后端未启动或未登录时，界面保持本地模拟模式。新增“智能记账”独立页，并按“交易类型 → 一级分类 → 二级分类”实现三级联动，完整映射 68 个 `CategoryId`；借款与还款合并为“借贷”入口。账户转账会按照接口约定提交一笔负金额转出和一笔正金额转入。

## AI 接口配置

「AI 财富管家」当前**已接入 DeepSeek**（Key 写在 `app.js` 的 `AI_CONFIG` 中），未配置或调用失败时自动回退本地模拟回答。有两种配置方式：

1. **代码内配置**：修改 `app.js` 顶部的 `AI_CONFIG`（当前生效）。
2. **页面内配置**：进入 AI 财富管家页，点标题右侧的 **⚙ AI 设置**，填写 Base URL、模型名和 API Key（只保存在本机 `localStorage`，优先级高于代码配置）。

```js
const AI_CONFIG={
  baseUrl:'https://api.deepseek.com',      // DeepSeek 路由地址（不含 /chat/completions）
  model:'deepseek-flash',                  // 默认使用最新 DeepSeek v4.1 系列
  apiKey:'sk-...',                         // 填入 Key 即自动启用；留空则用本地模拟回答
  temperature:0.7,
  maxTokens:1600                           // 单次回复上限（含推理 token），防止意外消耗
};
```

> DeepSeek 账号下实测可用模型：`deepseek-flash`（默认，快）、`deepseek-v4-pro`（更强）。两者均为推理模型，约 2~8 秒出字，页面上会先显示「正在思考…」。

- 支持所有 **OpenAI 兼容** 接口，浏览器可直连（CORS 预检已实测通过）：DeepSeek、智谱 GLM、Kimi、硅基流动、OpenRouter。
- 提问会自动带上**用户画像**（姓名、年龄、学校专业年级、城市、住校情况、收入来源、消费习惯、储蓄动机、近况）与**财务数据**（总资产、本月收支、预算使用率、储蓄目标及完成度、本月完整流水），回答更贴合场景、更有人味。
- 内置系统提示词约定了 AI 的**职责**（看懂钱 / 管好钱 / 存下钱 / 陪伴成长）、**回答规则**（称呼用户、只依据真实数据、150 字内、给下一步动作）与**合规边界**（不推荐个股、不承诺收益、反诈提醒）。
- 支持**流式输出**（打字机效果）；接口报错或未配置时**自动回退**本地模拟回答，演示不会冷场。
- 页面加载时**不发任何网络请求**，只有点击「发送」或推荐问题才会调用接口。

> ⚠️ **安全提示**：把 API Key 写在前端代码里，任何访问者都能查看源码并盗用，仅适合本地演示或个人使用。
> 公开部署（如 GitHub Pages）时建议改用无服务器代理，把 Key 放在服务端环境变量里 —— 前端只需把 `baseUrl` 指向你的代理地址即可，其余代码不用改。
